# Governance

- **Model:** benevolent dictator (BDFL) until there are 5 active maintainers; then a steering committee elected by maintainers.
- **Maintainers:** @RafaelJCamara.
- **Decisions:** recorded as ADRs ([docs/adr](docs/adr/README.md)). Changes to RabbitMQ semantics (the semantics registry) require an RFC issue, lab evidence recorded by CI, and maintainer approval.
- **Releases:** one product version, cut by merging the release-please release PR; only maintainers merge it.
- **Support and adopters:** see [SUPPORT.md](SUPPORT.md) and [ADOPTERS.md](ADOPTERS.md).
- **Licence:** Apache-2.0, forever; the core licence will not change and no feature will move behind a paywall ([ADR-031](docs/adr/ADR-031-fully-open-source.md)).
- **Trademarks:** see [TRADEMARKS.md](TRADEMARKS.md).
