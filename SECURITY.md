# Security policy

Please report vulnerabilities **privately** through GitHub's private vulnerability reporting ("Report a vulnerability" on the Security tab). Do not open public issues for security problems.

- We acknowledge reports within 5 business days and coordinate disclosure.
- Supported versions: none yet (pre-release). A support/LTS policy will be published before Web 1.0 (milestone M1).
- Semantic-correctness problems (for example a wrong RabbitMQ behaviour cell that could drop messages) are treated with security-level priority.

See the [threat model](docs/architecture/threat-model.md).
