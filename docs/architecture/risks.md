# Architecture risks

> **Design-phase output (2026-10-16).** Amended by [`docs/plan/amendments.md`](../plan/amendments.md), which takes precedence, and re-sequenced web-first ([ADR-030](../adr/ADR-030-web-first-delivery-order.md), [`docs/product/milestones.md`](../product/milestones.md)). Content about a specific third-party product was removed under the docs policy ([ADR-034](../adr/ADR-034-docs-policy.md)).

| Risk | Mitigation |
| --- | --- |
| Registry cells are wrong or untested. Every cell is code-derived, so a wrong cell could drop production messages while the UI claims safety. | The conformance suite is on the critical path (WP-04/12) and checks three things against each other: the live run, independently recorded lab evidence, and the registry. Mutation testing runs nightly. Missing cells raise SemanticsGapError and fall back to conservative rules. Receipts show a confidence level, and unverified versions get conservative handling. |
| A DOWN signal overtakes a pipelined nack under Raft leader changes, causing failed-delivery counts on 4.3 despite the qos barrier. | Spike S-09 plus a nightly chaos run of thousands of peeks under leader transfer, asserting DC deltas. Mitigations: lazy channel close after the barrier, the hold journal, honest W-CRASH receipts, and a 5 s hold target. |
| Rescuing a doomed message fails mid-hold (confirm nacked, returned, blocked or timed out), and the return then drops or dead-letters it. | Before acquiring, preflight the rescue: simulate the queue's policy, declare an explicit classic queue, check permissions and alarms, and pre-arm the confirm channel. On failure, retry once on a fresh channel. The receipt and a high-severity audit row record rescue-failed. AI or unattended plans require a rescue preflight that passed within the last 60 s. |
| Replay or move on a finite-L QQ DLQ loses messages through returns (b.4 carry-over), crash-time DOWN, or misidentified duplicates on resume. | Prefetch 1. Gate the source with W-OVERLIMIT or W-BUDGET. The type system has no nack path for finite-L sources. Messages are parked by confirm on failure, cancel or drain. The journal is an at-least-once multiset that republishes when in doubt. Copies carry stamped replay ids. Conformance cells cover cancel, shutdown and crash mid-replay. |
| MessagePort plus inject adds latency or breaks HttpClient features such as progress, abort or binary bodies. | Spike S-01 targets p95 overhead of 2 ms or less and tests 16 MiB bodies. payloadAsStream chunking and abort wired to an AbortSignal handle the features. Exports go to disk. An engine-link worker is added only if decode cost is measured as a problem. A dev-only loopback transport sits behind the same EngineTransport. |
| Event-loop stalls delay watchdogs, heartbeats and nack flushes, so a performance problem becomes a message-safety bug. | An I-5 SLO gate in perf CI (p99 of 20 ms or less under sweep plus tap). Large bodies are parsed in a streaming worker, and capture ingest runs in a worker. Ports are async, so SQLite can move to a single storage worker if the gate fails. |
| The in-house Fastify kit grows into a homemade framework. | An ADR caps it at 800 LOC with full tests. Generators carry the conventions. Growth beyond the cap requires a new ADR, enforced by a CI LOC check on libs/engine/transport/kit. |
| Supply-chain drift: agents install npm 'latest' (TS 7, electron-builder 26.15.3, the oasdiff placeholder), or the release-age gate blocks a security fix. | Exact catalogs, a banned list, a dependency allow-list and licence and lockfile gates. Reviewed exact-version exclusions recorded in an ADR log. A security lane: override, exclusion, rebuild of every bundled artefact, then a patch release. Bundled artefacts get notices and SBOMs from the esbuild metafile. |
| The local IPC channel on Windows is exposed by the default pipe DACL, or an impostor engine squats the pipe. | A mutual HMAC challenge-response keyed from a user-only file, so no token travels over the pipe. Random pipe names and a 1 s auth timeout. Spike S-08 evaluates a server-PID and owner-SID check. Capability tokens are read-only by default and expire. |
| Docker local-web users publish the port publicly (0.0.0.0 or --network host). | The token is mandatory on every route. Host and Origin allow-lists cover loopback names and the configured public origin. A startup banner shows the correct -p 127.0.0.1 line. Docs forbid the unsafe forms, and E2E tests check the container-mode Host rules. |
| Team server v1 is a single point of failure, and a rollout or crash interrupts live sessions and pollers. | Recreate strategy with fast restart. Durable jobs resume from leases and checkpoints, and sessions resume within 30 s. The HA design (broker-shard leases, internal mesh) is specified behind interfaces that already exist. |
| Delegated OAuth is fragile across IdPs (audience, OBO or token exchange, 431 errors on large tokens), so long jobs stall. | IdP presets and a config validator, plus a token-size preflight. Jobs move to awaiting-credentials and never fall back silently. An explicit, audited service-account policy is available per connection. |
| Plan and approval payloads or journals leak PII on the team server. | AES-GCM field encryption with row-bound AAD. Approvers see masked previews, and unmasking needs permission and is audited. Payloads are purged when a plan expires or executes. Capture defaults are volatile, and prod indexes metadata only. |
| Audit history is rewritten by a database owner, or broken by a restore or retention run. | A DML-only app role (INSERT/SELECT on audit) with migrations run by a DDL Job. Hash-chain heads are anchored to WORM storage, a SIEM or a signed file. audit verify runs after restore and across partition drops. A nightly restore drill runs in CI. |
| Tap, quarantine and staging queue churn loads Khepri on 4.3 clusters. | Tap queues are reused across binding changes. Quarantine and parked queues are durable and created once per vhost. A declare token bucket of 1/s burst 5 applies per broker, plus a team churn budget, with a 429 on exhaustion. |
| Signing and distribution are infeasible: SignPath reputation or its 'no hacking tools' clause, MSIX with a utilityProcess, notarisation cost. | Store MSIX is the first-class channel and Apple notarisation starts on day one. The linter is framed as hygiene for brokers the user connected to, with no scanning. Spike S-10 tests MSIX, and Certum is the fallback. |
| Third-party plugins or crafted payloads exhaust resources or execute code. | A QuickJS-WASM sandbox for third-party code, with memory, time and input caps. Built-in codecs run in workers with resource limits and decompression caps. Pickle and PHP payloads are never deserialised. A sha256 allow-list applies on the team server. |
| UI and engine version skew in long-lived browser tabs causes ChunkLoadError loops after an upgrade. | The image carries the hashed chunks of builds N and N-1. A global ChunkLoadError handler performs a single controlled reload that keeps the route. A version-mismatch banner and goaway prompt the user. |
| Scope is too broad for an agent-built v1, and features crowd out the safety core. | A core-first work-package graph. Feature WPs stay blocked until the executor and peek conformance are green. WPs are 1 to 3 days each, with executable verification. trust:critical paths require human review. |
