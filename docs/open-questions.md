| OQ-211 | Header types are inferred, not read from the wire. | amqplib decodes a field table into plain values and keeps the AMQP type only for timestamps and decimals: byte, short, int, long, their unsigned forms, float and double all arrive as JS numbers (a long above 2^53 loses precision before the adapter sees it). `TypedHeaderValue` wants a type, so integers are reported as `long` (the type RabbitMQ uses for `x-delivery-count` and `x-death.count`) and the rest as `double`; the IT shows a published `short` coming back as `long`.
