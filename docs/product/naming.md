# Naming candidates

The product name is **deferred** ([ADR-029](../adr/ADR-029-product-name.md), status Proposed). Until it is accepted, a private codename is used and nothing is published. RabbitMQ trademark rules: no "RabbitMQ"/"RMQ" in any identifier; use "<Name> for RabbitMQ®"; no RabbitMQ logos or rabbit imagery; Broadcom attribution required (see [TRADEMARKS.md](../../TRADEMARKS.md)).
